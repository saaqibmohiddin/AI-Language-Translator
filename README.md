## 🌍 PROJECT OVERVIEW

AI Language Translator is a multilingual communication application designed to help users understand and translate text across different languages.

It provides multiple tools for translation, document processing, voice interaction, smart writing, and translation management through an organized interface.

The project combines Python, Streamlit, HTML, JavaScript, and SQLite to provide a practical language-processing workspace.

## 💻 INSTALLATION & SETUP

### Prerequisites

- Python 3.x
- Visual Studio Code
- Git (optional)

### Step 1 — Clone the repository

```bash
git clone https://github.com/saaqibmohiddin/AI-Language-Translator.git
```

### Step 2 — Open the project folder

```bash
cd AI-Language-Translator
```

### Step 3 — Create a virtual environment

```bash
python -m venv venv
```

### Step 4 — Activate the environment

**Windows**

```bash
venv\Scripts\activate
```

### Step 5 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 6 — Run the application

```bash
streamlit run app.py
```

The Streamlit application will open in your browser.

**Browser-based interface:** Open `index.html` in a browser to use the separate HTML interface.
